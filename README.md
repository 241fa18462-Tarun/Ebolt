## 🖥️ Ebolt Workspace

The workspace provides a clean environment for managing your personal notes.

### 📝 Create

Create a new note with:

- Note title
- Note content
- Creation date
- Updated date

### ✏️ Edit

Open any existing note and modify its content whenever required.

### 🗑️ Delete

Remove notes that are no longer needed.

### 🔎 Search

Search through saved notes quickly using the built-in search interface.

### ↕️ Sort

Organize your notes using:

- Recently Updated
- Recently Created
- Title
